# Documentation & Site Tree Crawler

Інструментарій на Python для аналізу структури сайтів, побудови ієрархічних карт посилань та автоматичного вивантаження технічної документації у форматі Markdown.

Проєкт містить три автономні модулі під різні сценарії: швидкий аналіз безголовим HTTP-клієнтом, глибокий краулінг із рендерингом JavaScript та масовий збір структури сайту через Scrapy.

---

## Можливості та компоненти

### 1. Універсальний екстрактор документації (`dock_crawler.py`)

Орієнтований на вивантаження статей документації та збереження їх у локальні `.md` файли зі збереженням структури папок.

- Працює через **crawl4ai** (Headless Chromium), тому коректно підвантажує динамічні навігаційні блоки на клієнтських SPA/JS-сайтах.
- Має автоматичний фолбек на звичайні HTTP-запити через `requests` (допомагає проходити сайти з блокуванням автоматизованих браузерів чи захистом Cloudflare).
- Евристично вирізає навігаційне сміття: сайдбари, меню, плашки куків, хедери та футери.
- Дозволяє передавати кастомний CSS-селектор для точного вибору основного контенту.

### 2. Швидкий парсер структури та сирців (`main.py`)

Легкий інструмент на базі **trafilatura** та **BeautifulSoup** для швидкого аудиту сайтів або документацій на Sphinx / ReadTheDocs.

- **Дерево посилань (`--tree`)**: сканує внутрішні сторінки та виводить ієрархію шляхів прямо в термінал.
- **Збереження контенту (`--md`)**: конвертує статті в Markdown. Якщо сайт побудований на Sphinx, скрипт намагається завантажити оригінальні сирцеві файли `_sources/*.rst.txt`, забезпечуючи максимальну якість збереженого тексту.

### 3. Генератор XML-карти сайту (`site_tree_crawler/`)

Повноцінний проєкт на фреймворку **Scrapy** з модулем **scrapy-playwright**.

- Призначений для повного обходу великих порталів із динамічним JavaScript (наприклад, Unity ScriptReference).
- Будує точне дерево батьківських та дочірніх сторінок і зберігає результат в XML.
- `fix_xml_tree.py` — утиліта для постобробки зібраного XML: виправляє вкладеність, прибирає URL-параметри та дублікати.

## Встановлення

1. Встановіть залежності:

   ```bash
   pip install -r requirements.txt
   ```

2. Для модулів, що використовують браузерний рендеринг (Playwright / crawl4ai), завантажте браузер:

   ```bash
   playwright install chromium
   ```

## Приклади запуску

### Завантаження документації в Markdown (`dock_crawler.py`)

```bash
# Базовий запуск
python dock_crawler.py --url https://example.com/docs/ --output docs_export

# З вказанням CSS-селектора основного контенту
python dock_crawler.py --url https://example.com/docs/ --output docs_export --selector "article.doc-content"
```

### Перегляд структури або збереження через `main.py`

```bash
# Вивести дерево розділів у консоль
python main.py https://example.com/docs/ --tree

# Вивантажити сторінки в локальну папку (з пріоритетом на RST сирці)
python main.py https://example.com/docs/ --md
```

### Побудова XML-дерева сайту через Scrapy (`site_tree_crawler`)

```bash
cd site_tree_crawler
scrapy crawl site_tree -a start_url=https://docs.unity3d.com/ScriptReference/

# Виправлення структури згенерованого XML
python fix_xml_tree.py input_site_tree.xml
```
